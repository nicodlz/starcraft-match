## Reviewed region and caller

The complete contiguous body is `0x00401120..0x00401136`, 23 bytes,
including its sole plain return at `0x00401136`. Both conditional paths reach
that return. The previous routine returns at `0x0040111A`; inspected `INT3`
padding separates it from this entry. Padding after this routine starts at
`0x00401137`, and the next body starts at `0x00401140`.

Fresh pinned-PE disassembly establishes a direct call at `0x004D7DBF`.
The caller sets ECX from ESI at `0x004D7DBD`, calls this exact entry, then
jumps to `0x004D7500` without stack adjustment. At that destination it
overwrites EAX before use. This corroborates the pointer input and the entry;
it does not establish that a returned value has semantic meaning.

## Observed behavior and ABI

ECX points to an otherwise unnamed object. The function reads an unsigned
16-bit word at offset `0x0C`, with no null check. If bit `0x40` is set, it
clears that bit, sets bit `0x01`, and writes the 16-bit result back to the
same field. If bit `0x40` is clear, it performs no write. All other word bits
are retained. EAX contains the zero-extended original or updated word at
return. ECX is unchanged; no nonvolatile registers or stack arguments are used.

The independently authored C candidate uses a local minimal layout, an offset
assertion and a one-argument `fastcall` declaration to represent the observed
ECX input. Its unsigned EAX return captures the measured machine state, although
the inspected caller discards it. Field semantics and an original function name
remain unknown; no community implementation was consulted.

## Measurement

Clang 18.1.3 with both recorded `clang-i686-scaffold` and `clang-i686-size`
profiles emits 19 bytes against the complete 23-byte original. Strict isolated
COFF extraction accepts the function with zero relocations. Literal comparison
is **not exact**. The original clears EAX then loads AX, whereas Clang uses a
zero-extending word load. Clang also folds the mask plus bit setting into a
shorter immediate mask; the original uses a five-byte AND before its OR.
No bytes were trimmed, normalized or patched.

Private reproducible measurements use
`python3 .local/batch20_run/00401120/measure.py` after compiling the candidate
with the corresponding flags in `config/compilers.json`. Both profiles were
tested on the same final source. The proposed retained profile is
`clang-i686-scaffold`. Similarity scores, semantic match and original differential
execution remain unmeasured. Coordinator integration and independent rebuilding
are still required; this is a reconstructed mismatch candidate, not an exact
function milestone.
