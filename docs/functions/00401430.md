## Binary observations and ABI

Fresh extraction from the pinned PE shows a single 16-bit load at pointer offset
`0x64`. Unsigned comparisons reject values below `0xCB` and above `0xD5`.
The accepted path sets the full EAX result to 1 and returns at `0x00401445`;
the rejected path clears EAX and returns at `0x00401448`. Both branches stay
inside the reviewed region. The previous function returns at `0x00401426`,
followed by inspected `int3` padding through `0x0040142F`; padding after this
function begins at `0x00401449` and continues through `0x0040144F`.

Entry evidence is independent of padding: the direct call at `0x004C877F`
targets `0x00401430`. Immediately before it, `0x004C877D` copies EDI to EAX;
immediately after it, `0x004C8784` tests the full EAX result. Thus the observed
input pointer is in EAX and the result is a full-width 0/1 value in EAX. There
are no stack arguments, stack cleanup, outgoing calls, null checks or writes.
The body leaves every other general-purpose register unchanged. The selected
compiled candidate additionally clobbers ECX, so full ABI equivalence has not
been established. The pointer is assumed readable at the observed word offset.

## Independent reconstruction and measurement

The [C candidate](../../src/game/sub_00401430.c) uses a minimal local layout with
a checked `0x64` field offset, `regparm(1)` for i386 EAX input, one unsigned word
read, and the two observed bound conditions. No semantic field name or external
implementation is used.

Both `clang-i686-scaffold` (`-O2`) and `clang-i686-size` (`-Oz`) produce a
**20-byte** isolated COFF function with no relocations. Strict comparison of
the full **25-byte** original against each complete compiled section is
**not exact**. Clang folds the range into a subtract-and-compare operation,
uses ECX for the loaded value, and returns with `setb al` after zeroing EAX.
The original uses AX for the load and two conditional branches with separate
return paths. Neither extracted bytes nor source are patched to hide this
difference. The scaffold profile is retained for the proposed catalog entry.
