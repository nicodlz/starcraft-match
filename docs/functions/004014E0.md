## Observed behavior and ABI

The input pointer arrives in EAX. The function reads the unsigned WORD at offset
`0x64`, uses it as a four-byte-stride index into the table based at `0x00664080`,
and tests bit `0x08` of the indexed **BYTE**. If set, it reads the DWORD at input
pointer offset `0xC0`; otherwise it returns zero in the full EAX register. There
is no null or index check. ECX is clobbered; the function performs no stack
adjustment and uses plain returns.

The caller copies ESI into EAX at `0x0045E1FB`, saves the full returned EAX in EDI
at `0x0045E202`, and tests EDI for zero. On the nonzero path, it later reads WORDs
at returned-pointer offsets `0xD2` and `0xD0` (`0x0045E22C` and `0x0045E233`).
This supports a pointer-valued result. The candidate uses `regparm(1)` for the
EAX argument, neutral field names, and static offset assertions. Pointer field
semantics beyond those observed accesses remain unassigned.
