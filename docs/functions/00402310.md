## Observed ABI and behavior

The non-null object pointer arrives in EAX. The function reads one DWORD at object
offset `0xDC`, tests bits `0x3000`, and returns full EAX equal to 0 or 1. The original
clobbers ECX, accesses no stack arguments, and returns with a plain RET. Its first
read has no null check. No semantic name for the object or field is asserted.

[src/game/sub_00402310.c](../../src/game/sub_00402310.c) declares only the observed
field and its offset, with compile-time layout/width checks. `regparm(1)` expresses
the EAX input for i386 compilation; the volatile DWORD view preserves the observed
read width. The native fallback is only a source-compilation convenience.

## Remaining mismatch and limits

The original separately loads the DWORD into ECX, tests CH, and branches to two
full-EAX return paths. Clang uses a DWORD memory test and `setne` with zero
extension. This preserves the reconstructed predicate and access width but does
not reproduce the reviewed machine code. The retained profile is
`clang-i686-scaffold`; the size profile produced the same bytes.

The private experiment used the existing profile flags, fresh `PE.region`
extraction, strict `coff_function` extraction and literal `compare`. No bytes were
trimmed, normalized, embedded in the candidate or patched. No third-party
implementation was consulted. Original differential execution, field semantics,
and historical compiler reconstruction remain unestablished. The coordinator
