# 0x00402A70

The independently authored C candidate compiles to **22 bytes versus 24 original
bytes** with `clang-i686-scaffold`; the complete regions do **not** match.

## Pinned binary and boundary evidence

All observations refer to SHA-256
`ad6b58b27b8948845ccfa69bcfcc1b10d6aa7a27a371ee3e61453925288c6a46`
from `config/target.json`. Fresh PE-region disassembly establishes the contiguous
body at `0x00402A70` through `0x00402A87`, inclusive. Returns occur at
`0x00402A84` and `0x00402A87`; inspected alignment padding begins at
`0x00402A88`. The preceding function returns at `0x00402A62`, followed by
padding through `0x00402A6F`.

A direct call at `0x0046F1EA` independently corroborates the entry. Its preceding
instruction copies ESI to EAX; the instruction immediately after the call tests
full EAX. No stack argument is pushed or cleaned up for this call.

## Observed behavior and ABI

The input pointer arrives in EAX. The function reads one DWORD at pointer offset
`0xDC` and returns full EAX equal to one exactly when bit `0x800` is set and bit
`0x10` is clear; otherwise it returns zero. It does not write memory or check for
a null pointer. Both exits use plain `ret`. The original body changes EAX and
condition flags while leaving the other general registers untouched.

The candidate expresses the pointer argument with i386 `regparm(1)` and declares
only the observed offset. A volatile DWORD access retains the original read width.
The neutral field name `flags` describes bit use; no game meaning or authenticated
original symbol is claimed. No community implementation or external reference was
used to write this candidate.

## Reconstruction result and limitations

The ordinary two-condition candidate was compiled with both recorded Clang
profiles. Further bounded experiments tried a combined mask comparison and branch
likelihood hints under each profile, for eight source/profile variants total.
None matched. The final clean candidate uses `clang-i686-scaffold` and produces
22 bytes. Clang computes the predicate using shifts, `sete`, and a final `and`,
where the original has two conditional branches and separate constant returns.

The candidate additionally clobbers ECX and EDX. The inspected caller replaces ECX
before its next use and does not consume EDX afterward in the reviewed window, but
this does not prove their treatment at every incoming reference. Consequently,
full ABI compatibility is not asserted. Compiler allocation and register behavior
remain blockers to exact matching; unsupported similarity and semantic metrics
remain null. Strict isolated COFF extraction rejected relocations by construction;
no byte trimming, assembly embedding, or binary patching was used.

Private reports retain the fresh disassembly, whole-region comparison and build
command. This is source reconstruction and compilation only: no original-process
execution or differential function testing has been performed. Coordinator review
and an independent rebuild are required before catalog integration.
