## Observed behavior and independent candidate

The body first tests bit 1 of the byte at preferred-layout address `0x006D5A6C`,
then zero-extends the word at pointer offset `0xA8` into EAX. If the tested bit
is set, it shifts EAX left by four. It performs no stores or null check.
The maximum returned value is `0xFFFF0`; the reviewed callers consume only the
low word. These are binary observations; object and global semantic names remain
unknown, and no third-party implementation or semantic reference was used.

The candidate defines only the observed local layout, asserts the word offset,
