Reference decoding divides the unsigned identifier by 2,500, narrows the quotient
to **BYTE**, then subtracts that narrowed value times 2,500. It rejects a narrowed
pool index of eight or greater, a null base in the eight-DWORD table at
`0x0069A604`, a zero remainder, or a remainder greater than the signed WORD
limit reached through `0x006D5BFC`, converted to unsigned. Accepted references
use `base + remainder * 52 - 52`. Quotient truncation and negative-limit behavior
are preserved; no modern bounds check is added.

DWORDs at offsets 0/4 and the final head decode zero as zero, otherwise as a
one-based 20-byte-record index relative to the supplied pool. The four bytes at
offsets 8..11 remain untouched. The C layout checks the 20-byte record size.
