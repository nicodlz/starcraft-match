## Observed operation and ABI

The routine scans twelve DWORD pointers at `0x00597208`–`0x00597234` in
ascending order. Null entries are skipped. For each non-null pointer it tests
bit `0x10` of the byte at offset `0xDC`, returning DWORD zero immediately if
that bit is set. If all twelve entries are null or have that bit clear, it
returns DWORD one. It performs no stores, no whole-DWORD status read, and no
bounds check beyond the fixed table termination.

The one stack DWORD supplied by the dispatcher is ignored; `__stdcall` represents
its four-byte callee cleanup. Additional register inputs are also ignored. EAX
contains zero or one, ECX changes to the scan cursor, and DL becomes `0x10`;
upper EDX bits and other general registers are preserved. Flags change.
The source uses the signed pointer-address comparison observed in this fixed i386
address range; it is not a portable abstract-container API.
