## Observed behavior and ABI

ECX supplies an unchecked full DWORD index into the pointer table at
`0x0069A604`. Before indexing that table, the leaf reads the DWORD pointer
at `0x006D5BFC` and sign-extends its first WORD into a 32-bit bound.
It starts a counter at 1 and compares against that bound **unsigned**.
Thus a negative signed WORD becomes a large unsigned bound; the candidate
retains this behavior and adds no guard.

When the bound exceeds 1, it reads the indexed table pointer, adds `0x3C`,
and examines one byte per entry with stride `0x34`. A byte with bit `0x10`
set ends the scan before incrementing the counter. Otherwise it increments
the counter and advances the pointer, repeating while counter < bound.
The DWORD result is 1 exactly when the final counter equals the bound.
In particular bounds 0 and 1 return 0 and 1 without accessing the pointer
table. No null, index, source-length or traversal guard exists.

Only EAX, ECX and EDX are modified. Nonvolatile registers are preserved;
the leaf uses no stack arguments and has a plain return.
