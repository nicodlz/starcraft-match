`0x0043EF92`, a direct call at `0x0043EF96`, and full EAX tested at

bounds checks, returns full EAX zero or one, and uses plain `ret`.
ECX, EDX and flags change; ESI is saved/restored only on the nonzero path,
and other registers are preserved.

`0x00690110`. If zero, it returns zero without subsequent reads or writes.

threshold of 180, otherwise 120. It reads DWORD `0x0058D6F8` and subtracts
the first DWORD with unsigned wrapping. If that difference reaches or
exceeds the threshold, it clears the first DWORD and returns one; otherwise
it retains the DWORD and returns zero. Counter wrap/underflow and the lack
of input checks are preserved. No numeric field names are required by the
neutral candidate.

accepted no relocations and matched all 64 bytes without trimming,
normalization, assembly or patches. `/O1` instead produced a 61-byte mismatch
using a memory AND to clear the DWORD. This isolated result does not prove
the original compiler configuration. Instruction, CFG and semantic execution
