# 0x0045AEA0

**Exact: 69 original bytes / 69 compiled bytes**, using `msvc71-o2`.
The measured callee uses custom register inputs selected by historical compiler
optimization of a static C function and an ordinary C caller.

`ad6b58b27b8948845ccfa69bcfcc1b10d6aa7a27a371ee3e61453925288c6a46`.

all three returns at `0x0045AED1`, `0x0045AED8` and `0x0045AEE4` and the internal
two-byte alignment instruction at `0x0045AEAE`. The preceding function returns

starts at `0x0045AEE5` and ends before the next entry at `0x0045AEF0`.

## Caller and register ABI evidence

The direct caller at `0x0045B1D9` copies EBX to ESI and EDI to EDX immediately
before the call and tests full EAX afterward. Two further callers independently
corroborate the same register roles: `0x004C56DD` obtains EDX from global
`0x006509B0` and copies the DWORD at caller-object offset `0x14` to ESI;
`0x004C5734` likewise supplies that DWORD in ESI and the global index in EDX.
Both consume full EAX immediately afterward. No stack argument or stack cleanup
is associated with these calls; surrounding pushes save the caller's registers.

Observed inputs are a DWORD identifier in ESI and a DWORD index in EDX. The
result is full EAX equal to 0 or 1; EAX, ECX and flags are modified. EDX, ESI,
EBX, EBP and EDI remain unchanged. Plain `ret` is used on all paths.

## Behavior and source reconstruction

The callee scans consecutive DWORDs starting at `0x0051ACC0`, stopping at the
first zero. It returns 1 immediately if a nonzero scanned value equals ESI.
There is no independent length bound on this scan.

If the scan finds no match, it reads one byte at
`0x0057EEE8 + 36 * EDX`, with 32-bit unsigned address arithmetic. Byte value 1
returns 1; a value other than 7 returns 0; value 7 returns whether ESI equals
`0x75637352`. No index bound, pointer validation or memory write is present.
The source names `name` and `player` follow the community annotation and caller
context; the independently observed contract is the raw identifier/index behavior.

The independently authored C90 source declares a static `noinline` callee plus
`sc_probe_0045AEA0`, an ordinary C caller used only as compilation context. MSVC
13.10.3077 selects ESI and EDX for the static callee's parameters. This is a
measured compiler result, not a claim that the original source used this shape or
that an externally visible standard calling convention describes the callee.
The context caller is not reconstructed, matched or counted as a game function.
No assembly, ABI shim, copied implementation, embedded instruction bytes or patch
is involved. The final candidate symbol is the static `_sub_0045AEA0`.
