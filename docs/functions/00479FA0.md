## Observed behavior and ABI

The routine writes DL to object BYTE offset `0x4D`, then writes the target pointer
to object DWORD offset `0x5C`. For a nonzero target, it reads the target's pointer
at offset `0x0C`, copies its WORD at offset `0x14` to object offset `0x58`, reloads
the target pointer, and copies its WORD at offset `0x16` to object offset `0x5A`.
The pointer reload between stores is preserved for aliasing. For a zero target,
it clears object WORD `0x5A` before WORD `0x58`. Both paths clear BYTE `0x4E`
and write WORD `0x00E4` at `0x50`. No additional checks are imposed.

Inputs are object EAX, target ECX and byte DL. EAX stays the object pointer;
ECX is clobbered and EDX becomes zero. ESI is saved/restored on the nonzero path;
other nonvolatile registers are untouched. Stack cleanup is absent and flags
are clobbered. These are observations about this leaf, not an external cdecl
or fastcall declaration.
