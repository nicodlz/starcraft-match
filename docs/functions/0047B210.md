Otherwise the result is `0x0059CB58 + (input & 0x7FF) * 0x150`. The function reads
and writes no memory, uses a plain return, leaves the stack unchanged except for
the return address, and preserves non-EAX general registers. Nonzero inputs whose
low 11 bits are zero produce the base address, not a null result. No validity or
bounds check occurs. Flags are not claimed as a C interface contract.

The candidate uses i386 `regparm(1)` to express the EAX argument. A compiler branch
probability hint preserves the observed branch shape; it does not change C value
behavior. The meaning of the index, stride and base address is unassigned here.
No community naming or third-party implementation was used.
