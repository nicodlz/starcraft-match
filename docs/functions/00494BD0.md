## Observed behavior and ABI

Inputs occupy EAX and ECX. The body computes the low eight bits of their
32-bit subtraction, then returns that value when it is at most 128, otherwise
256 minus that value. The result is a complete EAX value between 0 and 128.
There are no memory accesses, outgoing calls or stack arguments. The body may
modify ECX; it preserves EDX and returns without stack cleanup.

The first caller moves a prior result to ECX, loads EAX from a local DWORD,
then compares the complete EAX result with a zero-extended WORD. The second
caller loads ECX from a zero-extended BYTE and EAX from a zero-extended WORD,
then compares EAX with a WORD carried in DX. This confirms that EDX must survive
this call. No semantic function name or external implementation was consulted.
The behavior is consistent with a distance on a ring of 256 values; that
interpretation is a hypothesis rather than an authenticated name.

The independent candidate uses Clang's i386 `regcall` for EAX/ECX arguments and
an unsigned integer return. Its generated leaf also preserves EDX. This is a
local ABI representation, not a claim about the historical calling convention.
