## Observed behavior and ABI

The first signed INT arrives in EAX, the second in one DWORD stack slot. The result
occupies AX only; upper EAX bits are not normalized. EBP and ESI are preserved,
ECX, EDX and flags change, and RET 4 discards the stack argument.

The function loads a DWORD base pointer at `0x006D5BFC`. It divides both inputs
by 32 with signed truncation toward zero, forms the wrapping 32-bit offset
`((unsigned)(first / 32) << 8) + (unsigned)(second / 32)`, and reads a WORD at
`base + offset*2 + 0x0C`. If that WORD is at least `0x2000`, it instead returns
the WORD at `base + id*6 + 0x1400E`. It adds no coordinate clamp, table bound,
null check, or index subtraction. This unsigned shift/add expresses observed
wrapping arithmetic, including negative inputs, without signed-overflow assumptions.
