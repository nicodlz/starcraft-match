## Accesses and custom ABI

EAX supplies the node pointer and remains unchanged at return. ECX and
EDX may be modified; nonvolatile registers are preserved. The leaf has
a plain return and does not access its stack.

It reads the DWORD pointer at `0x00628430` into a local head pointer.
For a nonnull head, it compares the DWORD pointer at `0x0059CC9C`
against that head and replaces the global with the input node if equal.
It then writes head to node+0, reads head+4 and writes that pointer to
node+4, **rereads head+4 after the write**, and conditionally writes the
node to the reread pointer's +0. Finally it writes node to head+4.
Every link access is DWORD-wide. The two head+4 reads are retained in
the source, including their order relative to node stores; no disjointness
or alias restriction is assumed.

If the head is null, the leaf writes node first to global `0x0059CC9C`
and then to global `0x00628430`, and does **not** initialize the node's
two link fields. No null guard protects the input node. The candidate
preserves this behavior rather than adding a conventional list initializer.
