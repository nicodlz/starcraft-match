## Observed behavior and ABI

The routine traverses twelve records backwards with stride `0x24`. It reads a
byte at `0x0059BF44` on the first iteration and ends with `0x0059BDB8` inclusive.
For each record, it reads the first byte, changes it to `6` if its original value
was `5`, `3`, `4` or `7`, and then writes zero to the byte at record offset `2`.
The conditional store precedes the unconditional store. No other record bytes
are read or written. The source retains that order and does not add a range
normalization or table-based membership test.

There are no register or stack arguments, and return uses plain `ret`. ECX changes,
AL changes, and DL is zeroed; the upper EAX/EDX bits and other general registers
remain preserved. Flags change. The caller ignores the incidental register values.
The selected compiled function reproduces these effects by literal byte equality.
