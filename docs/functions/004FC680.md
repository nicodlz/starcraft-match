# sub_004FC680

The complete **11-byte** function matches independently authored pure C exactly
with `clang-i686-scaffold`. Strict isolated COFF extraction reports no relocations.

## Specimen and boundaries

These observations apply to Windows i386 1.16.1 SHA-256
`ad6b58b27b8948845ccfa69bcfcc1b10d6aa7a27a371ee3e61453925288c6a46`. The complete region is
`[0x004FC680, 0x004FC68B)`, including its final return.

The final RET is at `0x004FC68A`. A preceding routine returns at
`0x004FC67A`, with INT3 padding through `0x004FC67F`. Trailing INT3 padding
runs from `0x004FC68B` through `0x004FC68F`. The initialized data pointer
at `0x0050C110` names this entry within the startup callback interval
`[0x0050C000, 0x0050C4BC)`. Fresh inspection of the startup loop at
`0x00404E95` through `0x00404EB3` shows the table bounds, four-byte stride,
null-pointer skip and indirect CALL EAX at `0x00404EAC`. This independently
corroborates the mapped entry.

This is a static data initializer, not a gameplay routine. It reads one DWORD
from `0x004FF8F8` and writes that value to `0x006D5FD0` in that order.
The input data has bits `0x7F800000` in this specimen; the C source copies the
observed DWORD rather than embedding that value or assigning floating semantics.

The pinned [BWAPI map](https://github.com/bwapi/bwapi/blob/d727fed68558c506163048ea889131d8cbb33915/Release_Binary/Starcraft/bwapi-data/data/Broodwar.map) independently corroborates entry and size under
community annotation `_initFloat_49`; this is not an original symbol.

## ABI and validation

No observable arguments. Plain RET, with only EAX changed; all other
general-purpose registers are preserved. The inspected startup dispatcher
pushes no arguments for the callback, ignores its EAX value, and advances its
table pointer in ESI after return. The void C candidate preserves those effects.
The destination and source accesses are both 32 bits and remain ordered.

The source is `src/game/sub_004FC680.c`. The experiment rebuilds with the
recorded profile, uses `PE.region`, `coff_function`, and `compare` across the
entire original region and isolated candidate section, and rejects relocations.
No byte normalization or trimming was performed. Private reports remain under
`.local/hundred/004FC680/`.  No original-process or differential execution was performed.
