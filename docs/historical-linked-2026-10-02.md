# First audited-linkage function lot

**Six newly reviewed functions / 1,093 original bytes** match after coordinator fresh-source compilation and genuine GNU ld linkage. The complete milestone is **269 functions / 13,806 bytes**, including 76 static data initializers / 836 bytes and 193 other functions / 12,970 bytes. There are 276 public source candidates. This is about 6.40% of the 4,201 community-map entries by listed-function count, without a code-size or completion claim.

Every claimed entry has a separately corroborating decoded original caller, reviewed neighboring boundaries and ABI notes tied to the SHA-256 in config/target.json. Neutral names remain in the catalog. The coordinator compiled the final public C sources using MSVC 13.10.3077, resolved complete explicit symbol bindings, preserved whole code/debug sections, independently checked ABI/boundaries, and reran individual required-exact matches. No padding or plausible C alone establishes an entry.

The native and portable [linkage tools](relocation-linking.md) were independently reviewed and tested with synthetic C/COFF/PE input before these sources were accepted. Raw relocation-bearing objects remain rejected. Unsupported metadata, unused/missing/aliased bindings, warnings and component drift fail. Backend success alone does not establish original ABI or entry evidence.

Regional byte comparisons contain every genuinely resolved relocation word. No source includes assembly copies or original-byte arrays, and no output is trimmed, patched or normalized. The same C sources also compile and link under the recorded portable profile, which always has proof/ABI qualification disabled. No original differential execution, full-program linkage, playable-game or complete-compiler reconstruction is claimed. External Storm implementations were unavailable; their imported interfaces and preservation remain explicitly inferred where noted. Source valid-object, aliasing and index bounds are not silently strengthened.

Local validation passed: `make` ran 123 tests, `make proof` rebuilt all 269 exact functions, and a checkout without the game or historical toolchain compiled all 276 sources and passed 87 tests with two explicit skips. The publication guard runs before committing. Public source-only CI cannot reproduce original-game comparisons without the legally held pinned executable. All original bytes, comparisons, native compiler/runner binaries and generated images remain in ignored local directories.
